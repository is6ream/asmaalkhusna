# Асма аль-Хусна — интерактивная HTML-презентация

React + TypeScript + Vite. Отдельное локальное приложение; существующие PPTX, PDF, изображения и конфигурации сохранены.

## Запуск

PowerShell:

```powershell
cd "C:\Users\is6re\Desktop\Asma al Khusna pitch\html-presentation"
npm.cmd install
npm.cmd run dev
```

Обычно: http://127.0.0.1:5173/ . Если этот порт занят: `npm.cmd run dev -- --port 5174`.

## Production

```powershell
npm.cmd run build
npm.cmd run preview
```

Production-сборка — `dist/`. Preview: http://127.0.0.1:4173/ . Открывайте по HTTP, а не двойным кликом по index.html: ES-модули требуют локального сервера. Сборка статическая, пути относительные; backend не требуется.

## Управление

- Содержание в шапке и стрелки переключают разделы. На мобильном — естественная вертикальная прокрутка и меню.
- Прямые ссылки: `#cover`, `#problem`, `#learning`, `#two-worlds`, `#adult`, `#international`, `#approach`, `#sustainability`, `#outreach`, `#roadmap`, `#team`, `#support`.
- Клавиши ← / → и PageUp / PageDown работают вне элементов интерфейса. Фокус в приложении или кнопке не переключает презентацию.
- Полноэкранный режим включается в шапке и имеет явный выход.
- Детская демонстрация: раздел «Учебный путь» (`#learning`). Взрослая: `#adult`. Из раздела «Два режима» есть переходы к обеим.
- «Смотреть демонстрацию» запускает последовательность. Есть пауза, повтор и сброс. «Попробовать» и действия внутри телефона прекращают автоматику.
- Показ останавливается при уходе из раздела и скрытии вкладки. При `prefers-reduced-motion: reduce` вместо таймера доступен «Следующий шаг».
- «Увеличить демонстрацию» открывает ту же сцену с теми же состояниями. Escape возвращает к тому же разделу; фокус возвращается к кнопке открытия.

## Источники и переменные

Содержание — корневой `01_GAMMA_SLIDES.md`. Единственный источник сумм и сроков — корневой `VARIABLES.json`, импортируемый в `src/model.ts`. Редактируйте его и пересобирайте приложение; dev-сервер отслеживает изменения. Не требуется править JSX.

Производные поля `developer_total_calculated` и `total_months_calculated` намеренно не используются: стоимость труда и длительность вычисляются из первичных значений. Интервалы roadmap последовательны. Известные статьи суммируются отдельно, `null` отображается как «Уточняется». Частичная сумма не называется полным бюджетом.

## Сценарии

Взрослый: главная → уроки → имя → значение → тест → обратная связь → результат → повторение → прогресс. Работают ошибки и повторные попытки, избранное, возврат к незавершённому учебному экрану и сброс.

Детский: герои → карта → локация → имя → значение → история → задание → обратная связь → результат → учебная награда → обновлённая карта. Работают повторение, коллекция, мягкая ошибка и пояснение о следующей локации.

Состояние живёт в текущем сеансе страницы. Перезагрузка начинает демонстрации заново. Оба способа просмотра используют одни компоненты и reducer.

## Ресурсы и границы концепции

Локальные Montserrat и Noto Naskh Arabic; иллюстрации из `output/assets` текущего проекта, технически оптимизированные в WebP. Все тексты и кнопки — HTML. Религиозное содержание требует экспертной проверки; проверенного аудиоматериала нет, поэтому воспроизведение явно недоступно. Другие уроки и родительская зона относятся к будущей реализации. Четыре языка — план продукта, текущая демонстрация на русском.

Не подключены внешние сервисы, аналитика или платежи. Сайт не публиковался, commit/push не выполнялись.
