React + TypeScript + Vite. Отдельное локальное приложение; существующие PPTX, PDF, изображения и конфигурации сохранены.

## Управление

- Содержание в шапке и стрелки переключают разделы. На мобильном — естественная вертикальная прокрутка и меню.
- Прямые ссылки: `#cover`, `#problem`, `#learning`, `#two-worlds`, `#adult`, `#international`, `#approach`, `#sustainability`, `#outreach`, `#roadmap`, `#team`, `#support`.
- Клавиши ← / → и PageUp / PageDown работают вне элементов интерфейса. Фокус в приложении или кнопке не переключает презентацию.
- Полноэкранный режим включается в шапке и имеет явный выход.
- Детская демонстрация: раздел «Детский режим» (`#learning`). Взрослая: `#adult`. Из раздела «Два режима» есть переходы к обеим.
- «Смотреть демонстрацию» запускает последовательность. Есть пауза, повтор и сброс. «Попробовать» и действия внутри телефона прекращают автоматику.
- Показ останавливается при уходе из раздела и скрытии вкладки. При `prefers-reduced-motion: reduce` вместо таймера доступен «Следующий шаг».
- «Увеличить демонстрацию» открывает ту же сцену с теми же состояниями. Escape возвращает к тому же разделу; фокус возвращается к кнопке открытия.

## Источники и переменные

Тексты веб-презентации — `src/main.tsx` и внешнее описание демонстраций в `src/Demo.tsx`. Итоговый текст всех 12 разделов после редактуры 12 ноября 2026 — `SLIDE_COPY.md`. Корневой `01_GAMMA_SLIDES.md` сохранён как исходный сценарий Gamma и автоматически с веб-версией не синхронизируется.

Единственный источник финансов и сроков — корневой `VARIABLES.json`, импортируемый в `src/model.ts`. Длительности, названия этапов, интервалы и общий срок дорожной карты вычисляются из него. После изменения конфигурации пересоберите приложение; dev-сервер отслеживает изменения. Финансовые данные и их вычисления сохранены, но суммы и детализация бюджета на слайдах больше не выводятся.

## Сценарии

Взрослый: главная → уроки → имя → значение → тест → обратная связь → результат → повторение → прогресс. Работают ошибки и повторные попытки, избранное, возврат к незавершённому учебному экрану и сброс.

Детский: герои → карта → локация → имя → значение → история → задание → обратная связь → результат → учебная награда → обновлённая карта. Работают повторение, коллекция, мягкая ошибка и пояснение о следующей локации.

Ручной прогресс сохраняется локально раздельно для двух режимов, включая незавершённую попытку и контекст. Автопоказ использует отдельный сеанс в памяти с теми же компонентами и reducer; кнопка «К моему прогрессу» возвращает сохранённое ручное состояние. Сброс выбранного режима требует подтверждения при наличии результата.

## Проверка

```powershell
$env:QA_URL='http://127.0.0.1:4173/'
npm.cmd run qa
node qa-finish.mjs
node qa-focus.mjs
node qa-config.mjs
node qa-editorial.mjs
```

Требуется установленный Microsoft Edge. `qa.mjs` сохраняет проверяемые результаты в `audit/browser-results.json`, скриншоты — в `screenshots/`. `qa-editorial.mjs` проверяет семь ширин, обрезание текста, шрифты, удаление бюджетных блоков и увеличенный просмотр обоих приложений; сохраняет `audit/editorial-results.json` и обновляет `SLIDE_COPY.md` из отрисованной страницы. Текущий отчёт — `EDITORIAL_QA_REPORT.md`; `QA_REPORT.md` описывает предыдущую версию.

Для проверки новой логики:

```powershell

npm.cmd run qa
npm.cmd run qa:model
node qa-product-accessibility.mjs
node qa-config.mjs
node qa-design.mjs
```

`npm run qa` теперь запускает `qa-product.mjs`; машинный отчёт и скриншоты: `audit/product/`. Старые `qa.mjs`, `qa-focus.mjs`, `qa-finish.mjs` сохранены как проверки предыдущего контракта экранов; их предположения о незапоминаемом состоянии, сбросе без подтверждения и пути через список уроков устарели. Их функциональные проверки включены в новую матрицу; адаптивность всей презентации по-прежнему проверяет существующий `qa-design.mjs`.

Локальные данные находятся в `asma-demo-v2-adult` и `asma-demo-v2-kids`. Повреждённая/несовместимая запись сбрасывается только в своём режиме; при запрете хранилища приложение работает до перезагрузки и сообщает об ограничении. Данные не отправляются на сервер. Автопоказ не записывается и после перезагрузки возвращается ручной контекст.
