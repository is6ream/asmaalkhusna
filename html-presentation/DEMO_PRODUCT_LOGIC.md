# Логика демонстрационного продукта

Объём: один учебный пример Ар-Рахман из существующего проекта. Существующее визуальное направление, 12 разделов и материалы сохранены. Новые религиозные сведения не добавляются.

## Найденные разрывы
Нет персистентности; главная предлагает продолжение до начала; возврат всегда ведёт к списку; карточка из избранного теряет источник; повторение раскрывает ответ сразу; карта обещает открытие отсутствующего урока; автопоказ и сброс затрагивают ручной результат; прогресс сравнивается с 99 вместо доступного одного урока.

## Общая модель и проверка согласованности
Два независимых версионированных localStorage-ключа. Сохраняются экран, история возврата, последний учебный шаг, признак незавершённой текущей попытки, ответ, завершение, избранное, факт повторения. Проверяются типы, допустимые экраны режима и семантические ограничения; при несовместимых данных сбрасывается только соответствующий режим. Ошибки чтения/записи оставляют рабочий сеанс в памяти с пояснением. Персональных данных нет.

Навигационные разделы обнуляют стек возврата, но сохраняют учебный шаг. Внутренние переходы кладут предыдущий экран в стек; Назад извлекает его. Завершение не отменяется возвратом. Избранная карточка — отдельный контекст: возврат ведёт к избранному, её открытие не начинает урок. Активный пункт меню отражает контекст, включая карточку/внутренние шаги. Каждый экран допускает выход через меню.

| Состояние | Действие / условие | Следствие | Назад |
|---|---|---|---|
| Главная взрослого | Начать / продолжить / повторить | Новый урок / сохранённый шаг / отдельное повторение | На главной скрыт |
| Вход ребёнка | Начать | Карта | На входе скрыт |
| Карта / уроки | Открыть доступный модуль | Цель ребёнка или имя взрослого; начатый модуль продолжается | Корневой раздел |
| Цель → имя → значение | Основное действие | Следующий учебный шаг, без начисления прогресса | Предыдущий шаг |
| Значение ребёнка → ситуация | Прочитать, перейти к заданию | Вопрос по существующей истории | Значение |
| Задание | Выбрать / изменить | Только выделение ответа | Предыдущий учебный экран |
| Задание | Проверить при выбранном ответе | Объяснение ошибки или верного ответа | Вопрос, выбранный ответ сохранён |
| Ошибка | Повторить | Новый выбор, завершение недоступно | Вопрос |
| Верно | Завершить | Один изученный модуль; одна учебная звезда ребёнку | Назад к объяснению без отмены результата |
| Результат ребёнка | Посмотреть награду → карта | Карта «Пройдено», 1 имя в коллекции | Предыдущий экран |
| Коллекция | Открыть изученное | Карточка имени; начать повторное прохождение | Коллекция |
| Повтор взрослого | Вспомнить → открыть ответ → самооценка | Отмечен факт повторения, число имён неизменно | Назад к предыдущему разделу; меню доступно |
| Избранное | Добавить / удалить | Один общий флаг во всех представлениях, прогресс неизменен | Карточка возвращается в источник |
| Пустая коллекция / повтор / избранное | Объяснение + доступное действие | Переход к реальному первому модулю / карточке | Корневой раздел |
| Следующая локация | Статичное пояснение | Не обещает доступного урока | Не интерактивна |
| Сброс с учебным результатом | Подтвердить / отменить | Только выбранный ручной режим / состояние неизменно | Escape отменяет |

Награда выводится из complete и не накапливается. Повторное прохождение сбрасывает только текущую попытку. Если оно прервано, карта/главная предлагают продолжить его, даже когда первое завершение уже учтено. Завершить можно только после верного ответа. Незавершённый шаг сохраняется при переходе в меню, закрытии увеличения и перезагрузке. Самооценка повторения не выдаётся за экзамен или интервальную систему.

## Автопоказ
Отдельный явно подписанный сеанс в памяти, тот же reducer и те же действия. Ручной localStorage не записывается; кнопка «К моему прогрессу» восстанавливает ручной снимок. Нажатие внутри телефона останавливает таймер и позволяет исследовать показ. Пауза сохраняет шаг, продолжение запускает следующий доступный переход, повтор начинает чистый показ. Скрытие вкладки и уход из раздела прекращают таймер. Reduced motion: только пошаговые действия. Увеличение перемещает ту же сцену без сброса, замыкает фокус и возвращает его при Escape.

## Содержание
Нужны экспертная проверка существующего перевода, пояснения и детской методики, проверенная аудиозапись и материалы остальных имён. Текущий один модуль не является библиотекой 99 уроков.
